# 本地视频库

一个纯前端、零后端、零依赖的本地视频管理网站。所有数据存储在浏览器 LocalStorage 中，开箱即用，无需任何服务器配置。

## 功能亮点

- **纯本地存储**：视频以 Base64 形式存入浏览器 LocalStorage，不上传任何服务器，完全离线可用
- **分类管理**：侧边栏展示所有分类，支持一键切换筛选；上传时可选择分类；点击加号即可添加新分类
- **即点即播**：视频卡片点击直接弹出播放器，支持全屏、倍速、进度拖拽等原生控制
- **备份与恢复**：一键导出完整备份 JSON 文件，可随时导入恢复，换设备/换浏览器轻松迁移
- **存储监控**：实时显示 LocalStorage 使用量，接近上限时自动变色预警
- **拖拽上传**：支持点击选择和直接拖拽视频文件到上传区域
- **右键管理分类**：在侧边栏分类上右键可进入分类管理，支持重命名和删除
- **响应式暗色主题**：自适应布局，暗色护眼界面，支持移动端浏览

## 支持格式一览

| 格式 | 上传 | 播放 | 备注 |
|------|------|------|------|
| MP4 | ✅ | ✅ | 推荐格式，兼容性最佳 |
| WebM | ✅ | ✅ | 体积较小，适合网页 |
| MOV | ✅ | ✅ | Apple 设备常用 |
| AVI | ✅ | ⚠️ | 部分浏览器可能不支持播放 |
| MKV | ✅ | ⚠️ | 编码兼容性因浏览器而异 |
| OGV | ✅ | ✅ | 开源格式 |
| 备份 JSON | ✅ | ✅ | 用于导出/恢复完整数据 |

> ⚠️ 视频文件通过 Base64 编码后体积会膨胀约 33%，建议单个视频控制在 **3MB 以内**，总存储不超过 **4.5MB**（LocalStorage 通常限制 5-10MB）。

## 隐私与安全

- **零网络传输**：所有视频数据仅存在于你的浏览器本地存储中，不会发送到任何服务器
- **无账号体系**：无需注册、登录，无第三方追踪
- **数据完全属于你**：备份 JSON 文件可导出到本地硬盘，随时带走
- **清理风险**：清除浏览器缓存/LocalStorage 会导致数据丢失，**请务必定期导出备份**
- **同源限制**：LocalStorage 按域名隔离，不同浏览器、不同域名之间数据不互通

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Esc` | 关闭任何打开的模态框（上传/播放/分类管理等） |
| `Enter` | 在添加分类输入框中按回车确认添加 |
| `拖拽` | 将视频文件直接拖入上传区域的虚线框内即可上传 |

## 技术栈

- **HTML5** — 语义化结构、Video 标签原生播放
- **CSS3** — Flexbox + Grid 布局、CSS 变量主题、动画过渡
- **Vanilla JavaScript** — 无框架依赖，原生 DOM 操作
- **LocalStorage API** — 本地持久化存储
- **FileReader API** — 客户端文件读取与 Base64 编码
- **Blob & URL API** — 备份文件导出

## 使用提示（踩坑经验）

1. **存储容量是硬限制**：LocalStorage 一般只有 5MB，视频转 Base64 后体积会变大。如果上传失败或页面卡顿，说明容量已满，需要删除旧视频或导出备份后清理
2. **大视频会卡死**：超过 5MB 的视频在转 Base64 时可能导致浏览器无响应，建议先用工具压缩后再上传
3. **浏览器兼容性**：Chrome / Edge / Firefox / Safari 均支持，但 IE 不支持
4. **隐私模式/无痕模式**：部分浏览器在无痕模式下 LocalStorage 不可用或退出即清空，请勿在无痕模式下长期使用
5. **备份文件很大**：因为包含 Base64 视频数据，备份 JSON 可能达到数 MB，导入时耐心等待，不要重复点击
6. **分类删除不可逆**：删除分类时，该分类下的视频会自动移至「未分类」，不会丢失
7. **换浏览器/换电脑**：数据不自动同步，必须通过「导出备份 → 复制文件 → 新环境导入备份」迁移
