# 本地视频库

一个纯前端、零后端、零依赖的本地视频管理网站。视频文件保存在浏览器 **IndexedDB** 中，分类配置保存在 **LocalStorage** 中，无需账号或服务器。

## 功能

- **本地视频存储**：视频以 `Blob` 形式保存到 IndexedDB，不上传服务器。
- **分类管理**：添加、切换、重命名、删除分类；删除分类时其中的视频自动转移到「未分类」。
- **即点即播**：视频卡片点击打开原生 HTML5 播放器。
- **备份与恢复**：导出包含分类和视频内容的 JSON；恢复时会把 Base64 视频重新转换为 Blob 后存入 IndexedDB。
- **存储监控**：优先使用浏览器 `StorageManager.estimate()` 获取当前存储配额，并显示估算占用比例；上传前会检查剩余空间。
- **大容量视频**：不再设置 5MB 总容量限制；视频直接以 Blob 保存到 IndexedDB。单个文件仅设置 2GB 安全阈值，实际总容量由浏览器配额决定。
- **拖拽上传**：支持点击选择和拖拽视频文件。
- **移动端侧边栏**：手机端通过汉堡按钮打开分类侧边栏，点击遮罩或切换分类即可关闭。
- **响应式暗色主题**：桌面、平板和手机均有适配。

## 实际存储架构

```text
浏览器
├── LocalStorage
│   └── 分类配置
│       └── videoLib_cats_v1
│
└── IndexedDB
    └── VideoLibraryDB / library
        └── videoLib_v1
            └── videos[]
                ├── Blob 视频文件
                ├── name
                ├── category
                ├── size
                ├── type
                └── createdAt
```

新版本不再把视频 Base64 字符串作为主要存储格式。旧版本已经存在的 Base64 视频仍可直接读取和播放。

## 支持格式

上传本身由浏览器文件类型识别控制；实际播放能力取决于浏览器支持的容器和编码。

| 格式 | 上传 | 播放 | 说明 |
|---|---|---|---|
| MP4 | ✅ | ✅* | 推荐，通常兼容性最好 |
| WebM | ✅ | ✅* | 现代浏览器支持较好 |
| MOV | ✅ | ⚠️ | 取决于浏览器和内部编码 |
| AVI | ✅ | ⚠️ | 容器和编码兼容性差异较大 |
| MKV | ✅ | ⚠️ | 取决于浏览器版本与编码 |
| OGV | ✅ | ⚠️ | 浏览器支持情况不同 |
| JSON | — | — | 仅用于备份/恢复 |

`*` 是否能够播放最终取决于视频编码，例如 H.264/AAC 等。

## 大容量说明

视频上传不会先转换为 Base64，而是直接以 Blob 写入 IndexedDB，因此不会产生 Base64 约 33% 的额外体积。浏览器提供的 `StorageManager.estimate()` 只能作为配额估算，实际可用容量受浏览器、系统、设备剩余空间和站点策略影响。

> 注意：导出备份仍然会把视频转换为 Base64 写入 JSON，所以大型视频库不适合频繁生成单个超大的 JSON 备份文件。

## 备份说明

备份 JSON 为了实现跨浏览器、跨设备迁移，会把视频 Blob 转换为 Base64 写入 JSON。因此：

- 备份文件可能比原视频明显更大。
- 大量视频一起备份时会占用较多内存。
- 手机端建议分批备份，避免一次生成非常大的 JSON。
- 备份完成后请妥善保存 JSON 文件。

恢复备份时，程序会把 JSON 中的 Base64 数据重新转换为 Blob，再保存到 IndexedDB。

## 存储说明

本项目现在使用 IndexedDB，因此不能再用“LocalStorage 只有 5MB”作为视频容量限制。实际可用空间由浏览器、操作系统、设备剩余空间、站点存储策略等共同决定。

页面底部的存储条会优先尝试读取浏览器提供的存储配额；由于不同浏览器实现不同，它属于估算值，不是硬性上限。

程序对单个文件设置了 **2GB 的安全提示上限**。这不是浏览器真实容量上限，主要用于避免移动端误选超大文件导致明显的写入压力。实际总容量由浏览器的 IndexedDB 配额决定，不再限制为 5MB。上传前会尝试检查可用空间，并在可用时请求持久化存储。

## 隐私与安全

- 视频不会通过本项目代码主动上传到服务器。
- 没有账号体系，也没有项目自己的第三方追踪代码。
- 视频数据属于当前浏览器的当前站点存储。
- 清除网站数据、浏览器存储或部分隐私模式环境可能导致数据丢失。
- 不同域名、不同浏览器之间默认不共享 IndexedDB 数据。
- 如需迁移，请使用“导出备份 → 保存 JSON → 新环境恢复备份”。
