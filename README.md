# 本地视频库

一个纯前端、零后端、零依赖的本地 MP4 视频管理网站。

视频文件保存在浏览器 **IndexedDB** 中，分类配置保存在 **LocalStorage** 中，无需账号、无需服务器。

## 功能

- **本地 MP4 存储**：视频以 Blob 形式保存到 IndexedDB。
- **原文件保存**：上传时不转码、不压缩，不修改原始 MP4 文件。
- **分类管理**：添加、切换、重命名、删除分类。
- **删除分类自动归档**：删除分类后，其中的视频自动转移到「未分类」。
- **即点即播**：点击视频卡片打开 HTML5 原生播放器。
- **原文件下载**：可以直接下载已经保存的原 MP4 文件。
- **备份与恢复**：导出包含分类和视频内容的 JSON 备份。
- **存储监控**：使用浏览器 StorageManager API（可用时）估算存储空间。
- **拖拽上传**：支持点击选择和拖拽 MP4 文件。
- **移动端侧边栏**：手机端通过汉堡按钮打开分类侧边栏。
- **响应式暗色主题**：适配桌面、平板和手机。

## 视频格式

本项目目前专门用于管理 **MP4 视频**。

| 格式 | 支持 |
|---|---|
| MP4 | ✅ |

推荐使用：

- H.264 视频编码
- AAC 音频编码

具体能否播放仍取决于当前浏览器对 MP4 内部编码的支持。

项目不会对视频进行转码。

上传的 MP4 会直接以 Blob 保存到 IndexedDB。
